How Stack Works

Opening symbols are pushed. A closing symbol pops the top and must match it.

    How It Works

    A stack is LIFO (Last In, First Out): the most recently opened bracket must be the first one closed.

    1. Create an empty stack.
2. Read the input one character (or tag) at a time.
3. Opening bracket  → push it onto the stack.
4. Closing bracket:
     a. stack empty?        → error: unexpected closing bracket
     b. else pop the top and compare its type
5. Types differ?            → error: report the FIRST mismatch
6. After the last character, stack not empty?
                            → error: unclosed opening bracket
7. Stack empty and no error → BALANCED
    ⏱️

    Time: O(n)

    Each character is visited once; push and pop are O(1).

    💾

    Space: O(n)

    Worst case, every character is an opening bracket on the stack.

    🏷️

    Tags

    Same idea: push <name>, and a closing </name> must match the top. Void tags (img, br, hr, input, meta…) are never pushed.
